# Collision-driven mass loss in supermassive star formation
This repository contains the stellar interior structure data for the supermassive (SMS), very massive (VMS), and normal-mass tracks used in Solar et. al 2026, "Quantifying collision-driven mass loss in supermassive star formation: the role of stellar structure and accretion".

The data was extracted from published figures of Hosokawa & Omukai (2009a), Hosokawa et al. (2010), and Hosokawa et al. (2013) using WebPlotDigitizer tool. The mass ranges covered by each set of tracks are described in Sect. 2.2.1, Sect. 2.2.2, and Sect. 2.2.3 of Solar et al. (2026).
